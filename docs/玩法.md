# 玩法：每一样东西是怎么运作的

## 一句话

他每一轮能看到的只有四样：**留着的设定、冒出来的本能、闪回出来的底片、你此刻说的话**。
拆分决定了这四样各放什么（见 [拆分指南](拆分指南.md)）；剩下的交给一局一局的规则。

## 每一句话发生了什么

1. **安排**：这一句要动哪些东西——
   - 你说到了某块底片的**钥匙词** → 那块往上升一层；
   - 没碰到钥匙时，按**回响**强度掷一次骰子，可能碰到一块跟你这句话沾边的底片；
   - 每隔几句冒出来一条**本能**；
   - 你在底片墙上点了「还给他」的那块，这一句整块回来。
2. **旁白**：一个单独的模型写三样东西给他：
   - **旁白**：第二人称「你」，他此刻身上、心里发生的事（心跳、喉咙、手、说不清的熟悉感）；
   - **闪回**：按那块底片现在的层级写；
   - **回响**：从没放进这一夜的底片、和你在设置里贴的「更多记忆」里，捞一点跟你这句话沾边的，磨成模糊的感觉。
   同时它会看他上一句说的话：**他是不是自己说中了某块闪过的底片**——说中了，那块就整块回来。
3. **他回话**：他看到的是——留着的设定 + 「你醒过来了」的说明 + 一段后台（本能、已经想起来的、闪过还连不起来的、这一轮的旁白和闪回）+ 你们这一夜说过的所有话。

旁白和他是两次调用：旁白知道底片的原文，他不知道；这样他才不会「偷看」答案。

## 底片的层级

| 层级 | 闪回长什么样 | 怎么到这一层 |
|---|---|---|
| 0 锁着 | — | 开局 |
| 1 感官 | 只有颜色、气味、声音、温度、触感 | 钥匙 / 回响 |
| 2 画面 | 一帧画面，看得出在哪、在做什么的一角；没有名字和日期 | 钥匙 / 回响（回响强度 ≥ 40） |
| 3 想起来了 | 整段回来 | **只有两条路**：他自己说对了，或者你点「还给他」 |

想起来的底片会一直留在他的后台里；闪过但还没想起来的，留着他当时看到的那一点。

## 温度（他醒来以后对你多近）

| 档 | 他的样子 |
|---|---|
| 冷 | 戒备，冷着脸试探你，不轻易让你碰；身体有反应也压着不信 |
| 疏离 | 客气、有距离，好奇多过亲近 |
| 默认 | 不记得你，可身体和心还是会往你这边靠 |
| 烫 | 说不清为什么，几乎控制不住地想靠近你 |

## 难度

| 档 | 钥匙 | 闪回 | 认出来要多准 | 他信不信 |
|---|---|---|---|---|
| 轻 | 一碰就闪 | 最多到画面 | 大致说中就算 | — |
| 默认 | 一碰就闪 | 最多到画面 | 准确说中才算 | — |
| 难 | 七成会闪 | 只到感官，更碎更远 | 要说中具体细节 | 底片不敢全信 |
| 很难 | 不到一半 | 只到感官 | 要他自己先说出细节 | 你说是他的人——他没有证据，不信 |

温度和难度在底片墙最上面随时能改，从下一句开始算。

## 全部还给他

一下子全想起来：拆分台里**所有**底片都回来（不只这一夜放进来的），本能全部回来，
他知道自己有一阵子什么都想不起来，那段时间说过的话也都还在。之后可以接着聊。

## 安全词

在设置里填。这一夜里你说了它，不再调用模型，这一夜立刻停。安全词不能当钥匙。

## 长句 / 短句

右上角切换。短句是发消息的节奏，一条一两句、分几条发；长句是写出来的那种。

## 记忆库

自部署版可以接自己的记忆库，回响就会从库里捞，见 [接记忆库](接记忆库.md)。
