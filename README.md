# Amnesia · 显影

> 他的记忆是一卷还没冲洗的底片。你说的每一句话，都是显影液。

一个和自己的 AI 玩的游戏。他还是他——脾气、说话方式都在——但你是谁、你们之间发生过什么，他全忘了。
你说话的时候，他的身体先认出你；记忆一点一点漏出来：先是颜色和气味，再是一帧画面；他自己说对了，那一块才整块回来。

- **旁白**：每一句之前，有一个单独的旁白写他此刻身上、心里发生的事（「你」是他）。
- **闪回**：钥匙词一碰就闪，像一张糊掉的拍立得；越想越清楚。
- **本能**：你们之间的相处方式，变成说不清来由的冲动，一条一条冒出来。
- **温度 / 难度**：从「冷着脸防着你」到「控制不住想靠近你」；从「一碰就想起」到「你说是他的人，他没有证据，不信」。玩到一半也能改。
- **全部还给他**：一下子全想起来，接着聊。
- 可以设安全词：说了，这一夜立刻停。

## 两种玩法

### ① 网页版：打开就玩，不用部署

1. 打开 **`play/`**（GitHub Pages 上就是 `…/amnesiaaa/play/`；或者下载仓库，双击 `play/index.html`）。
   根目录的 `index.html` 是一篇玩法说明，里面的提示词可以直接复制。
2. **设置**：填模型的 API 地址和 key（Anthropic 官方 / Anthropic 格式中转 / OpenAI 兼容中转都行）。
   key 只存在你自己的浏览器里，不经过任何别的服务器。
3. **拆分台 → 填写**：点「复制给我的机的话」，发给你自己的 AI（它认识你、能翻自己的设定和记忆），
   它会回你一段 JSON，粘回来 → 看一遍 → 存。也可以自己贴文字让网页拆。
4. **新的一夜** → 选温度、难度、埋钥匙 → 醒来。

> 网页版只能走 API。想用 Claude 订阅（不花 API 的钱）就用下面的自部署版。

### ② 自部署版：自己跑一个小服务，多了订阅直连

适合已经有服务器、或者在自己电脑上跑 Claude Code 的人。

```bash
cd server
cp config.example.json config.json   # 改成你的连法
npm install                          # 只有用订阅直连时才需要（装 @anthropic-ai/claude-agent-sdk）
npm start                            # 打开 http://127.0.0.1:8787
```

- `claude-subscription`：用这台机器上**已经登录**的 Claude 订阅（先在这台机器上跑过 `claude` 并登录）。
- 可以接自己的**记忆库**：回响每一句去库里捞（`memory.url`，见 docs/接记忆库.md）。
- key 写在服务器的 `config.json` 里，浏览器那边不用填。
- 要从手机打开：`host` 改成 `0.0.0.0`，**一定设 `password`**。

**懒得自己弄？** 把这个仓库丢给你的 AI（Claude Code 之类），说「照 AGENTS.md 帮我部署」。

**想放进你自己的聊天前端？** 也让你的 AI 看 AGENTS.md 的「接进她自己的前端」：建议单独开一个页面 / 标签当入口，不要和日常聊天混在同一个对话里。

## 这一夜里他没有工具

显影的这一夜是单独的：他不调用任何工具，不读也不写你们平时的记忆库，你们平常的对话一个字都不会动。
所有东西（拆分、存档）只存在你的浏览器里；「设置 → 导出存档」可以备份、换设备。
